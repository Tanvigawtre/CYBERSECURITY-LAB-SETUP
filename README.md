# CYBERSECURITY-LAB-SETUP
Cybersecurity lab setup using VirtualBox and Kali Linux for Week 1 practical.

## Overview
Created a cybersecurity lab using VirtualBox and Kali Linux for learning networking and cybersecurity.

## Tools Used
- Oracle VirtualBox
- Kali Linux
- 7-Zip

## Network Configuration
- Network: NatNetwork
- Subnet: 10.0.0.0/24
- IP Address: 10.0.0.2/24
- Gateway: 10.0.0.1
- DNS: 8.8.8.8

## Setup Steps
1. Installed 7-Zip and VirtualBox.
2. Created a NAT Network.
3. Imported Kali Linux into VirtualBox.
4. Configured the network adapter.
5. Set a static IP address.
6. Configured shared folders and clipboard.
7. Created a VM snapshot.

## Learning Outcomes
- Virtual machine setup
- Network configuration
- IP addressing
- Basic Linux networking
